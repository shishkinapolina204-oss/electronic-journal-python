# Электронный журнал успеваемости и посещаемости

Настольное приложение на языке Python для автоматизации учета успеваемости (по 10-балльной шкале) и посещаемости учащихся в КГУ «Жамбылская ОСШ».

## Технологии
- Python 3
- Tkinter (графический интерфейс)
- SQLite3 (локальная база данных)
- JSON / CSV (экспорт ведомостей)
- Unittest (модульное тестирование)
